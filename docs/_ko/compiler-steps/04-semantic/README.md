# 4. 의미 분석

> 공통 규칙은 [../README.md](../README.md)를 본다.

- 상태: 초안
- 이전 단계: AST 변환
- 다음 단계: Wasm 코드 생성

## 1. 하는 일

AST를 검증하고 코드 생성에 필요한 심볼을 확인한다.

### 처리 방식

- 심볼 정보를 이용해 노드 이름과 루프 변수의 참조를 확인한다. `1/(2-2)`처럼 분모가 상수식인 경우 AST를 유지하면서 분모를 계산해 0으로 나누는지 검사한다.
- 확인할 수 없는 참조와 상수식에서 0으로 나누는 경우를 검사한다.

## 2. 입력

- 출처: AST 변환
- 형식: AST 변환 단계가 만든 전체 또는 부분 AST.

아래 JSON은 데이터 구조를 보여 주는 예시다. 토큰과 트리는 일부만 표시했으며 필드명은 초안이다.

```json
{
  "kind": "Draw",
  "points": [
    {
      "x": 0,
      "y": 0
    },
    {
      "x": 1,
      "y": 0
    }
  ],
  "line": 1,
  "column": 1
}
```

## 3. 출력

- 형식: 분석한 AST와 심볼 정보.
- 화면에 보여주는 방식: AST 트리와 심볼 정보를 진단과 함께 표시한다.

### 출력 키

단계 출력의 최상위 키는 두 개다. 심볼 항목의 필드는 `symbols[]` 경로로 표시했다. 예시의 `ast`에는 `Draw` 노드 하나를 발췌했다.

| 키 | 타입 | 내용 |
|---|---|---|
| `ast` | 객체 | 분석을 거친 AST. [AST 출력 필드](../03-ast/README.md#3-출력)를 사용하고, 에러 복구 이후에는 부분 AST일 수 있다. |
| `symbols` | 객체 배열 | 분석 중 수집한 노드와 루프 변수 선언 목록. 빈 배열은 수집한 선언이 없음을 뜻한다. |
| `symbols[].kind` | 문자열 | 선언 종류. `node` 또는 `loopVariable`이다. |
| `symbols[].name` | 문자열 | 선언한 식별자. 루프 변수 이름은 앞의 역슬래시를 제외한다. |
| `symbols[].line` | 정수 | 선언 위치의 줄 번호. 1부터 센다. |
| `symbols[].column` | 정수 | 선언 위치의 열 번호. 1부터 센다. |

#### API 응답 키

공통 README의 응답 형식 초안은 `output`과 `errors`를 사용한다. JSON 예시는 `output`에 담기는 값만 보여 준다.

| 키 | 타입 | 내용 |
|---|---|---|
| `output` | 단계 출력 또는 `null` | 아래 예시에 해당하는 단계 데이터. 에러 복구 결과도 담을 수 있다. 반환할 결과가 없으면 `null`이다. |
| `errors` | 진단 객체 배열 | 이 단계에서 발생한 진단 목록. 진단이 없으면 빈 배열이다. |
| `errors[].kind` | 문자열 | 진단 종류. |
| `errors[].message` | 문자열 | 사용자에게 표시할 진단 메시지. |
| `errors[].line`, `errors[].column` | 정수 또는 `null` | 1부터 세는 소스 줄과 열. 소스 위치가 없는 진단에서는 둘 다 `null`이다. |

```json
{
  "ast": {
    "kind": "Draw",
    "points": [
      {
        "x": 0,
        "y": 0
      },
      {
        "x": 1,
        "y": 0
      }
    ],
    "line": 1,
    "column": 1
  },
  "symbols": []
}
```

## 4. 에러

| 종류 | 조건 | 메시지 예시 | 위치 정보 |
|---|---|---|---|
| 의미 | 참조한 노드에 접근 가능한 선언이 없음. | `undefined node 'B'` | 노드 참조. |
| 의미 | 루프 변수를 유효 범위 밖에서 참조했거나 해당 변수가 선언되지 않음. | `undefined loop variable 'i'` | 변수 참조. |
| 의미 | `1/0`, `1/(2-2)` 등 상수 분모의 계산값이 0임. | `division by zero` | 분모 식. |
| 의미 | 실수 좌표에서 `sqrt`의 상수 인자가 음수임. | `sqrt requires a nonnegative argument` | 인자 식. |
| 의미(조건부) | 중복 선언을 금지하는 경우 같은 범위에서 동일한 노드 이름을 두 번 선언함. | `duplicate node 'A'` | 뒤에 나온 선언. |
| 의미(조건부) | 문법에서 일반 함수 호출을 허용하는 경우 지원하지 않는 함수 이름을 사용함. | `unknown function 'tan'` | 함수 이름. |
| 의미(조건부) | 문법에서 길이가 가변적인 인자 목록을 허용하는 경우 함수의 인자 수가 맞지 않음. | `sqrt expects one argument` | 인자 목록. |
| 의미(조건부) | 반복 범위의 끝점이 정수 조건 등 정해진 범위 규칙을 어김. | `foreach bound must be an integer` | 잘못된 범위 끝점 식. |
| 의미(조건부) | 반복 범위가 오름차순만 허용되는 경우 내림차순 범위를 사용함. | `foreach range must be ascending` | 범위 식. |
| 의미(조건부) | 유한한 값만 허용하는 경우 숫자 리터럴 또는 상수 좌표 식의 값이 무한대나 NaN임. | `coordinate must be finite` | 리터럴 또는 좌표 식. |

조건부 항목은 합의가 필요한 문법과 의미 규칙에 따라 달라진다. 상수식을 검사할 때 AST는 그대로 유지한다. 루프 변수에 따라 값이 정해지는 식은 실행 중 검사가 필요할 수 있다.

- 에러가 났을 때의 복구 방식: 독립된 문장과 식의 검사를 계속한다. 이미 이름 해석에 실패한 참조 때문에 연쇄적으로 생기는 진단은 생략한다.
- 에러가 있을 때의 출력 형태: 분석 결과와 의미 진단을 반환한다. 컴파일 에러가 있으면 코드 생성을 건너뛴다.

## 5. API

- 엔드포인트: `POST /api/analyze` (제안)
- 요청 본문: 입력 절의 데이터를 받는다. JSON 필드명은 미정이다.
- 응답 본문: 출력과 진단 목록을 반환한다. 공통 README의 `output`과 `errors`는 응답의 초안이다.
