# 1. 렉서

> 공통 규칙은 [../README.md](../README.md)를 본다.

- 상태: 초안
- 이전 단계: 원본 MiniTikZ 소스
- 다음 단계: 파서

## 1. 하는 일

MiniTikZ 소스를 파서가 사용할 토큰 스트림으로 바꾼다.

### 처리 방식

- 토큰 규칙에 따라 명령, 이름, 루프 변수, 숫자, 구두점을 식별한다. `--` 같은 여러 글자 토큰은 접두사가 같은 한 글자 토큰보다 먼저 인식한다.
- 토큰으로 인식할 수 없는 문자를 보고한다.

## 2. 입력

- 출처: 사용자 입력
- 형식: MiniTikZ 소스 문자열.

아래 JSON은 데이터 구조를 보여 주는 예시다. 토큰과 트리는 일부만 표시했으며 필드명은 초안이다.

```json
{
  "source": "\\draw (0,0) -- (1,0);"
}
```

## 3. 출력

- 형식: 토큰 종류, 원문, 소스 위치가 붙은 순서 있는 토큰 목록.
- 화면에 보여주는 방식: 토큰 표.

### 출력 키

단계 출력은 소스 순서대로 정렬한 토큰 배열이다. 각 토큰은 다음 키를 가진다.

| 키 | 타입 | 내용 |
|---|---|---|
| `kind` | 문자열 | 토큰 종류. 예를 들어 `DRAW`, `NUMBER`, 입력 끝을 나타내는 토큰 등이 있다. |
| `lexeme` | 문자열 | 소스에서 일치한 원문. 예를 들어 `\draw`이며, 입력 끝 토큰은 빈 문자열이다. |
| `line` | 정수 | 토큰 첫 글자의 소스 줄 번호. 1부터 센다. |
| `column` | 정수 | 토큰 첫 글자의 소스 열 번호. 1부터 센다. |

#### API 응답 키

공통 README의 응답 형식 초안은 `output`과 `errors`를 사용한다. JSON 예시는 `output`에 담기는 값만 보여 준다.

| 키 | 타입 | 내용 |
|---|---|---|
| `output` | 단계 출력 또는 `null` | 아래 예시에 해당하는 단계 데이터. 에러 복구 결과도 담을 수 있다. 반환할 결과가 없으면 `null`이다. |
| `errors` | 진단 객체 배열 | 이 단계에서 발생한 진단 목록. 진단이 없으면 빈 배열이다. |
| `errors[].kind` | 문자열 | 진단 종류. |
| `errors[].message` | 문자열 | 사용자에게 표시할 진단 메시지. |
| `errors[].line`, `errors[].column` | 정수 또는 `null` | 1부터 세는 소스 줄과 열. 소스 위치가 없는 진단에서는 둘 다 `null`이다. |

```json
[
  {
    "kind": "DRAW",
    "lexeme": "\\draw",
    "line": 1,
    "column": 1
  }
]
```

## 4. 에러

| 종류 | 조건 | 메시지 예시 | 위치 정보 |
|---|---|---|---|
| 어휘 | 인식할 수 없는 문자(`@` 등). | `unexpected character '@'` | 해당 문자. |
| 어휘 | 명령이나 변수 이름이 뒤따르지 않는 역슬래시. | `expected a name after the backslash` | 역슬래시. |
| 어휘 | `12.3.4`처럼 형식이 잘못된 숫자 후보. 토큰 규칙이 이를 하나의 후보로 다루는 경우에 해당한다. | `invalid number literal '12.3.4'` | 숫자 후보의 시작. |
| 어휘 | 소스에 포함된 지원하지 않는 제어 문자(NUL 등). | `invalid control character U+0000` | 해당 제어 문자. |

세부 토큰 규칙은 미정이다. 역슬래시로 시작하는 이름의 형태가 올바르면 토큰화할 수 있으며, 명령 위치에서 허용되는지는 파서가 검사한다.

- 에러가 났을 때의 복구 방식: 잘못된 문자 하나 또는 형식이 잘못된 토큰 후보를 건너뛰고 다음 토큰 경계에서 스캔을 계속한다.
- 에러가 있을 때의 출력 형태: 소스 끝까지 인식한 토큰과 어휘 진단을 함께 반환한다.

## 5. API

- 엔드포인트: `POST /api/lex` (제안)
- 요청 본문: 입력 절의 소스를 받는다. JSON 필드명은 미정이다.
- 응답 본문: 출력과 진단 목록을 반환한다. 공통 README의 `output`과 `errors`는 응답의 초안이다.
